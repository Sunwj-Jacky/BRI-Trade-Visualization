# 一带一路经济走廊贸易演变可视化分析系统
BRI-Trade-Visualization 

## 项目简介

本项目是一个基于 Web 技术的交互式数据可视化平台，旨在探索和展示“一带一路”沿线国家及六大经济走廊在过去数年间的贸易结构演变。通过整合地理信息系统（GIS）与动态统计图表，用户可以直观地观察不同国家在能源、制造业以及农产品贸易领域的地位变迁，并分析不同经济走廊的增长轨迹。

## 核心功能

* **多维地理空间展示**：利用 Leaflet.js 构建交互式地图，支持按“一带一路”六大经济走廊（新亚欧大陆桥、中蒙俄、中亚-西亚、中南半岛、中巴、孟中印缅）进行筛选与高亮展示。
* **动态贸易趋势分析**：集成 D3.js 动态折页图，展示各国出口结构（农业、食品、燃料、制造品、矿物金属）的年度变化趋势。
* **交互式对比与联动**：支持通过地图点击或搜索框选择多个国家进行指标横向对比，实现地图视图与统计图表的实时联动。
* **时空演变回溯**：通过时间轴滑块，用户可回溯不同年份的贸易数据，观察全球化背景下区域贸易格局的重塑。

## 数据处理与分析

本项目对世界银行及相关贸易数据库进行了深入挖掘，重点处理了以下技术难点：

1. **指标辨析**：严格区分“货物贸易进口量（百分比变化）”与“货物和商品贸易进口量”等核心指标，确保学术表达的严谨性。
2. **走廊线路划分**：根据官方定义，将沿线国家精确归类至特定的经济走廊（如中巴经济走廊、新亚欧大陆桥等），并处理了多走廊交叉国家的逻辑分类。
3. **异常值挖掘**：通过探索性数据分析（EDA），识别出在特定年份贸易结构发生剧烈波动的亮点国家，并作为可视化展示的重点。

## 技术栈

* **前端框架**：HTML5, CSS3 (采用柔和的“新中式”配色方案)
* **可视化库**：D3.js (v7), Leaflet.js (v1.9)
* **数据格式**：JSON, CSV
* **部署平台**：GitHub Pages

## 部署说明

本项目已部署于 GitHub Pages。若需在本地运行，请执行以下步骤：

1. 克隆本仓库：`git clone [repository-url]`
2. 进入项目目录：`cd [directory-name]`
3. 使用本地服务器开启服务（推荐使用 VS Code 的 Live Server 插件或 Python 的 http.server）：
```bash
python -m http.server 8000

```


4. 在浏览器中访问 `http://localhost:8000` 即可查看。
